# Local fonts

Self-hosted WOFF2 subsets from Google Fonts for Manrope and IBM Plex Sans Thai. Original families and font names have not been changed.

Sources:
- https://fonts.google.com/specimen/Manrope
- https://fonts.google.com/specimen/IBM+Plex+Sans+Thai

Redistribution licenses are included in OFL-Manrope.txt and OFL-IBM-Plex-Sans-Thai.txt. app/fonts.css retains the supplied unicode ranges and uses font-display: swap. Asset file names are content hashes.
