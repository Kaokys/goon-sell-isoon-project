# Thai address dataset

Source: https://github.com/earthchie/jquery.Thailand.js

Downloaded raw_database.json from the project's master branch on 2026-09-24. 7,498 records; see THAI-ADDRESSES-LICENSE.txt for the upstream WTFPL license. Fields: province, amphoe (district), district (subdistrict), zipcode.

Used only on the server; the geography endpoint returns the relevant options. This is a reference dataset, not a live Thai Post address-verification service. Refresh the dataset when administrative boundaries or postal codes change.
